基于 EasyRPG Player 源码（`.tmp/Player/src/`）精确提炼，作为本工具渲染引擎的实现规范。所有坐标均相对 System 图片左上角，单位为像素。

## 2. System 图片布局（160 × 80）

System.png 总尺寸 **160 × 80**，带 alpha 通道。透明像素即 PNG alpha=0（典型 RM2k 资源中由原 BMP 透明色 #FF00FF 转换而来）。

### 2.1 区域划分总览

```
System.png (160 x 80)
+--------------------------------------------------------+
|  背景块        |     边框块 (8 子区域)              |   |
|  (0,0,32,32)   |  (32,0,32,32)                     |   |
|                |                                    |   |
|                |  +----+--------+----+              |   |
|                |  | UL |  Top   | UR |  y=0..8      |   |
|                |  +----+--------+----+              |   |
|                |  | L  | (arrow)| R  |  y=8..24     |   |
|                |  +----+--------+----+              |   |
|                |  | DL |  Down  | DR |  y=24..32    |   |
|                |  +----+--------+----+              |   |
+----------------+------------------------------------+   |
|                                                       |
|  配色块区 (20 色 + 阴影色)  y=32..80                    |
|                                                       |
+--------------------------------------------------------+
   x=0..32           x=32..64                          x=160
```

### 2.2 窗口背景块

- 源区域：`{0, 0, 32, 32}`
- 用途：窗口底纹，按 stretch/tile 模式铺满整个窗口矩形
- 透明像素：alpha=0 像素构成底纹镂空部分

### 2.3 窗口边框 8 个子区域（厚度 8px）

边框块整体位于 `{32, 0, 32, 32}`，按 8px 厚度切成 3×3 网格（中心格被箭头占用）。

| 区域 | 源 x | 源 y | 源 w | 源 h | 目标位置（窗口本地） | 绘制方式 |
|---|---:|---:|---:|---:|---|---|
| 左上角 UL | 32 | 0 | 8 | 8 | (0, 0) | Blit 1:1 |
| 上边 Top | 40 | 0 | 16 | 8 | (8, 0, w−16, 8) | TiledBlit, ox=8 |
| 右上角 UR | 56 | 0 | 8 | 8 | (w−8, 0) | Blit 1:1 |
| 左边 Left | 32 | 8 | 8 | 16 | (0, 8, 8, h−16) | TiledBlit, oy=8（仅 h>16） |
| 右边 Right | 56 | 8 | 8 | 16 | (w−8, 8, 8, h−16) | TiledBlit, oy=8（仅 h>16） |
| 左下角 DL | 32 | 24 | 8 | 8 | (0, h−8) | Blit 1:1 |
| 下边 Down | 40 | 24 | 16 | 8 | (8, h−8, w−16, 8) | TiledBlit, ox=8 |
| 右下角 DR | 56 | 24 | 8 | 8 | (w−8, h−8) | Blit 1:1 |

中心格 `(40, 8, 16, 16)` 不属于边框，被箭头使用：
- 上箭头：`(40, 8, 16, 8)`
- 下/暂停箭头：`(40, 16, 16, 8)`

### 2.4 配色块（20 色 + 阴影色）

- **阴影色块**：位于 `(16, 32)`，尺寸 16×16（用于文字右下 1px 偏移阴影）
- **20 色块**：10 列 × 2 行，每个 16×16，从 y=48 开始

色块 N（0 ≤ N ≤ 19）的左上角坐标：
- `x = (N % 10) * 16`
- `y = 48 + (N / 10) * 16`

| N | x | y | N | x | y |
|---|---|---|---|---|---|
| 0 | 0 | 48 | 10 | 0 | 64 |
| 1 | 16 | 48 | 11 | 16 | 64 |
| 2 | 32 | 48 | 12 | 32 | 64 |
| 3 | 48 | 48 | 13 | 48 | 64 |
| 4 | 64 | 48 | 14 | 64 | 64 |
| 5 | 80 | 48 | 15 | 80 | 64 |
| 6 | 96 | 48 | 16 | 96 | 64 |
| 7 | 112 | 48 | 17 | 112 | 64 |
| 8 | 128 | 48 | 18 | 128 | 64 |
| 9 | 144 | 48 | 19 | 144 | 64 |

取样时为避免边缘混入邻近色，建议取色块内部点：`src_x = (N % 10) * 16 + 2`, `src_y = 48 + (N / 10) * 16 + 2`（EasyRPG 用 +2/+4 偏移）。

## 3. 窗口背景渲染（RefreshBackground）

### 3.1 总体流程

1. 创建目标位图，尺寸 = `width × height`
2. 根据 `stretch` 选择绘制方式
3. 结果作为 `background` 缓存，Draw 时按 `back_opacity * opacity / 255` 不透明度 Blit 到屏幕

### 3.2 stretch = true（拉伸，RPG Runtime 默认）

- 将 System 的 `{0, 0, 32, 32}` 整体**缩放**到 `width × height`
- 等价 Canvas API：`drawImage(system, 0, 0, 32, 32, 0, 0, width, height)`

### 3.3 stretch = false（平铺）

- 将 System 的 `{0, 0, 32, 32}` 以 32 像素为周期**平铺**填满 `width × height`
- 平铺偏移 (0, 0)
- 等价 Canvas API：用 `createPattern` + `fillStyle`，或循环 `drawImage`

### 3.4 透明色处理

- EasyRPG 直接用 PNG alpha 通道，alpha=0 即透明
- `background_alpha`（每窗口，默认 false）：
  - false → 透明像素合成后写入**黑色**（不透明位图）
  - true → 透明像素保持**透明**（带 alpha 位图）
- `bg_preserve_transparent_color`（每 System 图，默认 false）：
  - true 时加载期对 `{0,0,32,32}` 背景块**跳过 alpha 预乘**，保留透明像素原 RGB（用于 RM2k 兼容、半透明消息框）
  - RM2k 模式下自动开启

### 3.5 本工具实现要点

由于本工具目标是导出**位图**（PNG），不需要"半透明叠在底层场景上"的视觉效果，建议：
- 默认采用 `background_alpha = true`（保留透明像素，便于后续导出指定透明色）
- 用户可在背景设置页选择"透明"开关，对应 `background_alpha`

## 4. 窗口边框渲染（RefreshFrame）

### 4.1 总体策略

- 边框**始终平铺**（TiledBlit），与 stretch 无关
- 4 个角直接 Blit（1:1，不缩放、不平铺）
- 4 条边以 16 像素为周期平铺，**偏移 ox=8（横边）或 oy=8（纵边）**——从源 tile 中点开始平铺，使图案关于窗口中线对称
- 仅当 `height > 16` 时才创建左右边

### 4.2 边框平铺的相位偏移含义

源 tile 是 16×8（横边）或 8×16（纵边）。EasyRPG 用 `(ox=8, oy=0)` 或 `(0, oy=8)` 作为平铺起点，意味着：
- 横边：从源 tile 的 x=8 开始平铺 → 窗口中线两侧图案对称
- 纵边：从源 tile 的 y=8 开始平铺 → 窗口中线上下图案对称

Canvas 实现建议：用 `createPattern` 后通过 `translate(8, 0)` / `translate(0, 8)` 偏移 pattern 变换矩阵。

### 4.3 边框与背景的合成顺序

`Window::Draw` 中的绘制顺序（后绘制覆盖先绘制）：

1. **背景**（`back_opacity` 控制）— 占满整个 `width × height`
2. **边框**（`frame_opacity` 控制）— 4 角 + 4 边覆盖在背景边缘 8 像素之上
3. **光标**（可选，本工具不涉及）
4. **内容**（contents，客户区 `(8, 8)` 起，尺寸 `(w−16, h−16)`）
5. **箭头**（可选，本工具不涉及）

## 5. 文字渲染

### 5.1 \c[N] 控制符语法

- 转义符默认 `\`（可被游戏修改）
- 后跟 `c` 或 `C`（大小写均可）
- 语法：`\c[N]`，N 为十进制数字序列
- **N 范围**：0..19 有效；**N > 19 → 回到 0**（不是取模）
- `\c[]`（空括号）→ 等价 `\c[0]`
- 不带 `[`（如 `\c5`）→ 退化为颜色 0
- Maniac 扩展：`\c[x,y]` → `text_color = y * 10 + x`（突破 20 色限制）

### 5.2 颜色作用范围

- 从 `\c[N]` 之后第一个字符起生效
- 持续到下一个 `\c[...]` 为止
- 换行 `\n`、换页 `\f` **不重置**颜色（颜色状态跨行跨页保留）
- 但每页开始（`InsertNewPage`）和消息处理开始（`StartMessageProcessing`）会把 `text_color` 重置为 0

### 5.3 其他文字控制符（参考）

| 控制符 | 含义 | 占宽度 |
|---|---|---|
| `\c[N]` / `\C[N]` | 颜色 | 否 |
| `\s[N]` | 速度 1–20 | 否 |
| `\_` | 半角空格 | 是（半个字宽） |
| `\$` | 显示金币窗 | 否 |
| `\!` | 文本暂停 | 否 |
| `\^` | 强制关闭当前页 | 否 |
| `\>` / `\<` | 即时速度开始/结束 | 否 |
| `\v[N]` | 变量值插入 | 否（替换后绘制） |
| `\n[N]` | 角色名插入 | 否（替换后绘制） |

本工具仅处理 `\c[N]`（颜色），其他控制符可作为普通文本或忽略。

### 5.4 字体选择规则（按语言推断）

EasyRPG 默认字体（`font.cpp:632-659`）：

| 语言区域 | use_mincho=false（Gothic/无衬线） | use_mincho=true（Mincho/衬线） |
|---|---|---|
| 日文 (CP932) | Shinonome Gothic | Shinonome Mincho |
| 简体中文 (CP936) | Shinonome Gothic（回退 WQY） | Shinonome Mincho（回退 WQY） |
| 繁体中文 (Big5) | Shinonome Gothic | Shinonome Mincho |
| 韩文 (CP949) | Shinonome Gothic（回退 Baekmuk） | Shinonome Mincho（回退 Baekmuk） |
| 其他（含英文/俄文） | ttyp0 | RMG2000-compatible |

`use_mincho` 来自游戏 System 设置中的字体选项（`Game_System::GetFontId()`）。

语言判定（`player.cpp`）：
- `IsCP932()` ← language == `ja_JP` 或 encoding == 932
- `IsCP949()` ← language == `ko_KR` 或 encoding == 949
- `IsBig5()` ← language == `zh_TW` 或 encoding == 950
- `IsCP936()` ← language == `zh_CN` 或 encoding == 936

### 5.5 字体度量

- 位图字体高度：12px
- 半角字宽：6px
- 全角字宽：12px
- 行高（消息框）：16px
- 字间距：默认 0
- 渲染方式：1-bit alpha，**纯像素化无抗锯齿**（FreeType 用 `FT_LOAD_MONOCHROME`）

### 5.6 文字绘制流程（Text::Draw）

1. 计算文字总宽度（累加每字形宽度）
2. 按 align 调整 x（左/中/右对齐）
3. 预留阴影空间：`width += 1; height += 1`
4. 逐字形渲染：
   - 字形位图作为 **mask**（alpha 通道）
   - System 图对应色块作为**填充源**（16×16）
   - 用 `MaskedBlit` 合成：字形像素 = System 色块颜色，字形外形 = 字形 alpha
5. 阴影绘制（`draw_shadow && color != ColorShadow`）：
   - 字形位图作为 mask
   - System 图 `(16, 32)` 阴影色块作为填充源
   - Blit 到目标位置右下偏移 **(1, 1)** 处
6. `color == ColorShadow`（-1）时只画阴影，不画主色

### 5.7 本工具实现要点（Web Canvas）

- 字形渲染：用 `fillText` 配合 `textBaseline = 'top'`，`fillStyle = system 色块颜色`
- 像素化效果：`ctx.imageSmoothingEnabled = false`，字体大小固定 12px
- 阴影：先在 `(x+1, y+1)` 用阴影色绘制一遍，再在 `(x, y)` 用主色绘制
- 全角/半角宽度：通过 `ctx.measureText` 测量，或按字符 Unicode 范围判断（CJK → 12px，ASCII → 6px）
- 控制符解析：用正则 `/\\c\[(\d*)\]/gi` 提取，分段渲染

## 6. 脸图（FaceSet）渲染

### 6.1 FaceSet 图片规格

| 项 | 值 |
|---|---|
| 单张脸图尺寸 | **48 × 48** |
| 网格布局 | 4 列 × 4 行 = 16 格 |
| face_index 范围 | 0–15 |
| FaceSet 图片总尺寸 | **192 × 192** |

### 6.2 face_index 到格子映射

```
src_x = (face_index % 4) * 48
src_y = (face_index / 4) * 48
src_w = 48
src_h = 48
```

| face_index | 源 x | 源 y |
|---|---|---|
| 0 | 0 | 0 |
| 1 | 48 | 0 |
| 2 | 96 | 0 |
| 3 | 144 | 0 |
| 4 | 0 | 48 |
| ... | ... | ... |
| 15 | 144 | 144 |

### 6.3 脸图在消息窗口中的位置

`Window_Message::WindowMessageValues` 枚举：
- `LeftMargin = 8`
- `FaceSize = 48`
- `RightFaceMargin = 16`
- `TopMargin = 8`

**脸图在左**（`face_right_position == false`）：
- contents 内坐标：`(8, 8)`
- 窗口坐标：**(16, 16)**
- 占据区域：(16, 16) → (64, 64)

**脸图在右**（`face_right_position == true`）：
- contents 内坐标：**(248, 8)**（硬编码）
- 窗口坐标：**(256, 16)**
- 占据区域：(256, 16) → (304, 64)
- 计算：248 = contents_width(304) − FaceSize(48) − LeftMargin(8)

### 6.4 脸图与文字区域的关系

| 布局 | 文字 x 起点（contents） | 文字可用宽度（contents） | 脸图占用宽度 |
|---|---|---|---|
| 无脸图 | 0 | 304 | 0 |
| 脸图在左 | **72**（=8+48+16） | 232 | 72 |
| 脸图在右 | 0 | 248 | 56 |

注意：脸图在左比在右多占用 16px（左布局有 `RightFaceMargin=16` 隔开文字，右布局没有等效左内边距）。

### 6.5 翻转支持

| 翻转类型 | 是否支持 | 实现 |
|---|---|---|
| 左右翻转（水平） | **支持** | `FlipBlit(..., flip_x=true, flip_y=false, ...)` |
| 上下翻转（垂直） | **不支持**（运行时） | `flip_y` 硬编码 false |

本工具可扩展支持上下翻转（用户需求），用 Canvas `scale(-1, 1)` / `scale(1, -1)` 实现。

### 6.6 透明色处理

- DrawFace 本身不处理透明色，仅 Blit
- 透明色由 FaceSet 图片加载时统一应用（RPG Maker 用 System 图左上角像素作为透明色）
- 本工具实现：FaceSet 加载时按选定透明色（默认左上角像素）转为 alpha=0

### 6.7 "空脸图" vs "无脸图"

EasyRPG 实现中是**二元**的：脸图区域要么完全不预留（`contents_x=0`），要么按完整 72px 预留。不存在"位置预留但不绘制脸图"的中间态。

本工具按用户需求扩展为三种状态：
- **无脸图**：不占空间（contents_x=0，全宽文字）
- **空脸图**：位置留空但不绘制（contents_x=72，但不画脸图）
- **有脸图**：位置预留并绘制脸图

## 9. 本工具实现映射（Web Canvas）

### 9.1 渲染管线

```
1. 加载 System PNG → ImageBitmap（带 alpha）
2. 解析配置（窗口尺寸、内边距、stretch 模式、脸图、文字）
3. 创建主 Canvas（width × height）
4. 绘制背景：
   - stretch=true → drawImage(system, 0,0,32,32, 0,0,w,h)
   - stretch=false → createPattern(system, 0,0,32,32) + fillRect
5. 绘制边框：
   - 4 角 → drawImage 1:1
   - 4 边 → createPattern + translate(8,0)/(0,8) 偏移 + fillRect
6. 绘制脸图（若启用）：
   - drawImage(faceset, srcX, srcY, 48, 48, dstX, dstY, 48, 48)
   - 翻转 → ctx.scale(-1,1) / ctx.scale(1,-1)
7. 绘制文字：
   - 解析 \c[N] 分段
   - 逐行逐字 drawText，配合阴影
8. 导出 PNG：
   - 8 位 PNG 量化
   - 透明色替换（用户指定或程序推荐）
```

### 9.2 关键 Canvas 设置

```js
ctx.imageSmoothingEnabled = false;  // 像素化，无抗锯齿
ctx.textBaseline = 'top';
ctx.font = '12px <font-name>';
```

### 9.3 8 位 PNG 导出

- 用 `OffscreenCanvas` + `getImageData` 取像素
- 量化到 256 色（保留透明色索引）
- 用 `pngjs` 或 `upng-js` 编码为 8 位 PNG
- 透明色推荐：深绿 `#003300` 或饱和较低的深蓝 `#000033`

### 9.4 默认值汇总

| 项 | 默认值 |
|---|---|
| 窗口宽度 | 320（标准） |
| 窗口高度 | 80（标准） |
